PHP-Parser as Foundation of Static Analysis Tools

What is PHP-Parser?

A PHP parser written in PHP. Its purpose is to simplify static code analysis and manipulation.
  • Parsing PHP 7 and PHP 8 code into an Abstract Syntax Tree
  • Traversing and modifying AST nodes
  • Converting an AST back to PHP code


Repository: nikic/php-parser

What is an Abstract Syntax Tree?

A data structure that represents the structure of a program.
The fundamental unit in the tree is called a .

Tools that use PHP-Parser

  • PHPStan: static analysis tool for PHP codebases
  • Rector: automated refactoring tool for PHP
  • StructArmed: configurable PHP architecture guard

How PHPStan uses AST generated by PHP-Parser

PHPStan traverses the code structure, inspects nodes such as function calls, method calls, property fetches, and variable assignments, then uses scope-aware type inference to understand the types of expressions.

Try PHPStan online

How Rector uses PHP-Parser AST and PHPStan type analysis

Rector traverses the code structure, gets type information from PHPStan when needed, applies transformations to matching AST nodes, and writes the changed AST back to PHP files.

Try Rector online

How StructArmed uses AST generated by PHP-Parser

StructArmed traverses the code structure, collects class and dependency information, then checks that information against defined rules to ensure that the code adheres to the desired architecture.
