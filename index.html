PHP-Parser as Foundation of Static Analytic Tools

What is a PHP-Parser?

A PHP parser written in PHP. Its purpose is to simplify static code analysis and manipulation.
  • Parsing PHP 7 and PHP 8 code into an Abstract Syntax Tree
  • Traverse and modify AST
  • Converting an AST back to PHP code


Repository: nikic/php-parser

Tools use PHP-Parser

  • PHPStan: Static analysis tool for PHP codebases
  • Rector: Automated refactoring tool for PHP
  • StructArmed: Configurable PHP architecture guards

How PHPStan uses AST generated by PHP-Parser

Traverse through the code's structure, inspecting various nodes (such as function calls, variable assignments, etc.) and set their associated types.

Try PHPStan online

How Rector uses AST generated by PHP-Parser and PHPStan

Traverse through the code's structure, get associated types from PHPStan, and apply transformations to the AST to write back to PHP files.

Try Rector online

How StructArmed uses AST generated by PHP-Parser

Traverse through the code's structure, and collect its AST information and dependencies of the classes and check them against the defined rules to ensure that the code adheres to the desired architecture.
